# Vue Journey – Thin, Pragmatic Frontend (Vue 3 + Vite + TypeScript)

This repo mirrors my other learning repos and focuses on **small, comprehensible Vue 3 examples** that serve as a thin presentation layer for backends.

---

## What to look at first

- **[SUMMARY.md](SUMMARY.md)** – index of examples and projects
- **[projects/](projects/)** – thin UIs talking to simple APIs (mocked or real)
- **[docs/architecture](docs/architecture/)** – decisions (why Vite, why TS, minimal state)

## Tooling

- Vue 3 + Vite + TypeScript
- Vitest for unit tests
- ESLint + Prettier

### Commands

```bash
npm i
npm run dev
npm run build
npm run preview
npm run lint
npm run test
```
